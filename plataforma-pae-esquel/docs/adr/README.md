# Registros de decisión de arquitectura (ADR)

Cada archivo documenta **una decisión, su contexto y sus consecuencias** — incluidas las
malas. Sirven para que dentro de dos años alguien (posiblemente vos mismo) entienda por
qué el sistema es como es, en vez de "corregir" algo que estaba decidido a propósito.

| ADR | Decisión |
|---|---|
| [001](ADR-001-reglas-antes-que-ml.md) | Motor de riesgo por reglas explicables, no aprendizaje automático |
| [002](ADR-002-monolito-modular.md) | Monolito modular, no microservicios |
| [003](ADR-003-evidencia-y-gamificacion.md) | Evidencia geolocalizada con minimización, y gamificación sin ranking |
| [004](ADR-004-indexacion-del-monto.md) | Actualización del monto por fórmula aprobada, no por decisión discrecional |
